1. 거품 정렬 (Bubble Sort)

거품 정렬은 인접한 두 원소를 비교하여 조건에 맞지 않으면 자리를 바꾸는 과정을 반복하는 간단한 정렬 알고리즘입니다. 시간 복잡도는 $O(n^2)$으로 다소 느리지만 구조가 직관적입니다. 

def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr
